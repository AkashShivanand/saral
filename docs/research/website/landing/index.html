Fifteen directions, one Saral

Each page is a full landing page for Saral in one visual direction: the same sections and copy, the same real components, a different identity. Open any two side by side at the bottom of this page. Every page works with JavaScript off.

Weights are first load, fonts included, as served by npm run serve; gzipped size is what a normal host sends. Contrast counts every text and control pair of the page’s theme in light and dark. Axe runs WCAG 2.2 A and AA rules seven times per page: light and dark at 1280 and 375 pixels, with every script blocked, with forced colours, and on the scripts-off form. The README has the full table.
