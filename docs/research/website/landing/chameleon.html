From the lab

Works without JavaScript

Open the frame: it cannot run any script, because its sandbox does not allow one. The form in it is the same Saral form. Try to send it empty, then fill it in.

  1. The browser stops the post and moves focus to the first field to fix.
  2. Each field you left wrong shows its error by CSS alone, with :user-invalid.
  3. Fill it in and it posts as a normal form, to a page that confirms it.
What the optional core script adds
  • Errors in the page’s own words, checked when you leave a field, never while you type.
  • Focus moves to the first error when you send.
  • The send button shows it is busy, so the form is not sent twice.
  • 8.1 kB of plain JavaScript (2.8 kB gzipped), with no dependencies.

Platforms

Use it where you build

One contract for every platform. A surface is published only when someone asks for it.

Today: the web

  • Any HTMLPlain pages, Rails, Django, Laravel, Go, .NET, htmx: if it writes HTML, it can use Saral.
  • npm: @saral/tokens, @saral/css, @saral/coreBuilt and checked on every change. The first release, 0.4.0, is being prepared.
  • A CDNThe same files, pinned to a version, from the first release.

Next

  • Figma variablesFrom the same token source. Target: the form patterns milestone, January 2027.
  • React adapter, @saral/reactIn the repository today, published with the first release.
  • @saral/elementsLight DOM custom elements, so Vue, Svelte, Angular and others can use the same parts. Planned, not built yet.

On request

  • iOS and AndroidNative components from the same contract, built when a team asks.
  • Other registries and token formatsSwift, Compose, Flutter and others, when someone asks in an issue.

Trust

Accessible by default, checked on every build

  • ContrastEvery text and control pair of this page’s theme is checked against WCAG 2 AA: 62 of 62 checks pass, in light and dark. The lowest is 4.54:1, for border.strong on surface.ground in light, against a minimum of 3:1.
  • KeyboardEvery part is a native element, so Tab, Space, Enter and the arrow keys do what the browser defines. Focus always shows as a ring.
  • Screen readersLabels, hints and errors are tied to their inputs. A manual pass with VoiceOver and NVDA is planned before a component leaves preview.
  • Forced colours and motionPages keep working in Windows High Contrast, and motion stops when you ask for less.
  • Read the accessibility statement (draft)
