Component

Button

Starts an action: submits a form or runs a command on the page.

Status
Preview
Since
0.2.0
Element
<button>
Script needed
None
  • Spec JSON
  • Markdown
  • Source
  • Report a problem

Example

The same button in six scripts 
<button data-scope="button" data-part="root" type="submit">Send message</button>
<button data-scope="button" data-part="root" data-variant="accent" type="button">Continue</button>
<button data-scope="button" data-part="root" data-variant="secondary" type="button">Save draft</button>
<button data-scope="button" data-part="root" type="button" disabled>Pay now</button>
<button data-scope="button" data-part="root" type="submit" aria-disabled="true" data-pending>Sending</button>

When to use it

Use it for

  • Submitting a form
  • An action that changes something on this page

Use something else for

  • Going to another page: use Link
  • Several actions of equal weight side by side: use Button with variant secondary for all but one

Accessibility

Native <button>. A pending button uses aria-disabled, not disabled, so it stays in the tab order and screen readers say why nothing happens.

KeyAction
Enter or SpaceActivates the button

On other platforms

iOS
SwiftUI Button; pending maps to .disabled with an accessibility hint
Android
Compose Button; pending maps to enabled = false with stateDescription

Writing

A verb first, one to three words, sentence case: Send message, Save changes. Never OK or Submit.

WriteSend message, Save changes, Pay now
AvoidOK, Submit, Click here

Recent changes

  • 2026-10-12Every component now also ships as its own file in dist/css/ (button.css, field.css, checkbox.css, radio.css, select.css, link.css, notice.css, tag.css, card.css), so a site loads only the parts it uses. components.css still holds them all.
  • 2026-10-12A fresh review before release found five problems, all fixed with tests (119 node, 53 browser): the select lost its arrow in Windows High Contrast; a whole-card link covered every button and plain link inside the card; unticking a required checkbox showed its error before screen readers were told; a removable tag did nothing without script (it now removes through a link, and React Tag takes removeHref); and a disabled select looked enabled.
  • 2026-10-12Field (label, input or textarea, hint, error), Button (primary, accent, secondary, pending), Link and Notice (info, success, warning, danger). Plain HTML and CSS that work with JavaScript off.
