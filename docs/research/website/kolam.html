What Saral promises

Plain HTML first

Every component is a native element with data-scope and data-part. It works before JavaScript loads, and without it.

Your look is a theme

Components read only semantic tokens. Change the theme and the whole interface follows. This page is one theme.

Rules that hold

Contrast, token use and naming are checked on every build. A text pair below 4.5:1 stops the release.

Use it where you build

Today

  • Any HTML: Rails, Django, Laravel, Go, .NET, htmx
  • React
  • Tokens as CSS, JavaScript and JSON

Planned for 1.0

  • Figma variables made from the same source
  • Tokens for Swift, Kotlin, Flutter, .NET and Python when a team asks
