# Saral phase 1 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A token compiler that turns DTCG token files for the ember and Mor themes into CSS, JavaScript and Tailwind outputs, refuses to build when a rule is broken, and proves ember matches akashshivanand.com value for value. Ends with tag v0.1.0 and the first public push.

**Architecture:** `packages/tokens/src/` holds small single-purpose modules: `resolve` (read the resolver, merge, flatten, aliases), `color` (colour maths and WCAG contrast), `checks` (the five build gates), `outputs` (CSS, JS, Tailwind text) and `build` (the CLI that ties them together). Token sources live in `tokens/`. Generated files go to `dist/` and are committed, because the website installs Saral from a GitHub tag with no build step. CI rebuilds and fails if `dist/` is stale.

**Tech Stack:** Node 24 (floor 20), `node:test`, no dependencies.

**Spec:** `docs/spec/2026-10-11-saral-v1-design.md`, sections 6 and 7, and the phase 1 row of section 13.

**Budget:** 5 evenings. Cut first if over: the Tailwind output, then Mor's dark mode.

## Global Constraints

- No runtime or dev dependencies. Node built-ins only. ES modules, `.mjs`.
- Token files follow DTCG 2025.10: colours are objects `{ "colorSpace", "components", "hex" }`, dimensions `{ "value", "unit" }`, durations `{ "value", "unit" }`. Saral-only data lives under `$extensions` key `in.akashshivanand.saral`.
- CSS custom property names are `--saral-` plus the token path with dots replaced by dashes (`surface.ground` becomes `--saral-surface-ground`).
- Theme CSS goes in `@layer saral.tokens`, with every selector inside `:where()`.
- Ember must equal the website's current values for every variable the website uses (fixture in Task 5). The website's `--quiet` is left out: the site never uses it, and it measures 2.95:1 on its own page background.
- Every contrast pair in `tokens/pairs.json` must pass in every theme and mode, or the build writes nothing.
- The repo is public: no private name anywhere. Docs copy: plain words, sentence case, no em dashes.
- Commit messages carry no AI co-author trailer. Log every change in `CHANGELOG.md`.
- The first public push needs Akash's go at that moment (Task 7), because the private name list must be complete first.

## Review Focus

1. **A hand-edited colour whose `hex` and `components` disagree.** Someone changes the hex and forgets the numbers. The build must stop and say which, not silently pick one. Pinned in Task 2.
2. **A role present in light but missing in dark.** The error must name the theme and the mode. Pinned in Task 5.
3. **Two theme files on one page.** Each theme's rules apply only to `:root` without a theme attribute or to its own `[data-saral-theme]` container, so the fixture page can show ember and Mor side by side. Pinned in Task 4.
4. **A person who forces light mode while their system is dark.** `[data-saral-mode="light"]` must keep the light values. Pinned in Task 4.
5. **Reduced motion.** Durations with a reduced value must drop to it under `prefers-reduced-motion: reduce`. Pinned in Task 4.

```js
// Reads DTCG 2025.10 token files: resolver documents, groups, $type
// inheritance and curly-brace aliases. Saral reads the subset it uses:
// sets and modifiers with { "$ref" } sources, and whole-value aliases.
import { readFileSync } from 'node:fs';
import { dirname, resolve as resolvePath } from 'node:path';
import { TokenError } from './errors.mjs';

const isObj = (v) => v !== null && typeof v === 'object' && !Array.isArray(v);

// Later sources win. Groups and tokens merge key by key, so a mode file can
// change a $value and keep the base file's $type; a $value itself is always
// replaced whole.
export function deepMerge(target, source) {
  for (const [k, v] of Object.entries(source)) {
    if (k !== '$value' && isObj(v) && isObj(target[k])) deepMerge(target[k], v);
    else target[k] = structuredClone(v);
  }
  return target;
}

export function loadResolver(file, input = {}) {
  const doc = JSON.parse(readFileSync(file, 'utf8'));
  const read = (src) => JSON.parse(readFileSync(resolvePath(dirname(file), src.$ref), 'utf8'));
  const tree = {};
  for (const set of doc.sets ?? []) for (const src of set.sources) deepMerge(tree, read(src));
  for (const [name, mod] of Object.entries(doc.modifiers ?? {})) {
    const context = input[name] ?? mod.default;
    const sources = mod.contexts?.[context];
    if (!sources) throw new TokenError(`${file}: modifier "${name}" has no context "${context}"`);
    for (const src of sources) deepMerge(tree, read(src));
  }
  return tree;
}

export function flatten(tree) {
  const out = new Map();
  const walk = (node, path, type) => {
    const t = node.$type ?? type;
    if ('$value' in node) {
      out.set(path.join('.'), { type: t, value: node.$value, extensions: node.$extensions ?? {} });
      return;
    }
    for (const [k, v] of Object.entries(node)) if (!k.startsWith('$') && isObj(v)) walk(v, [...path, k], t);
  };
  walk(tree, [], undefined);
  return out;
}

const ALIAS = /^\{([^{}]+)\}$/;

export function resolveAliases(tokens) {
  const done = new Map();
  const visit = (path, chain) => {
    if (chain.includes(path)) throw new TokenError(`alias cycle: ${[...chain, path].join(' -> ')}`);
    if (done.has(path)) return done.get(path);
    const tok = tokens.get(path);
    if (!tok) throw new TokenError(`${chain.at(-1)} points to {${path}}, which does not exist`);
    const m = typeof tok.value === 'string' && tok.value.match(ALIAS);
    let out = tok;
    if (m) {
      const target = visit(m[1], [...chain, path]);
      out = { type: tok.type ?? target.type, value: target.value, extensions: { ...target.extensions, ...tok.extensions } };
    }
    done.set(path, out);
    return out;
  };
  for (const path of tokens.keys()) visit(path, []);
  return done;
}
```

```js
// Colour maths for the token compiler: DTCG colour objects to sRGB, OKLCH in
// both directions, and the WCAG 2 contrast ratio. Everything is converted in
// this one place, so every output agrees.
import { TokenError } from './errors.mjs';

const clamp01 = (x) => Math.min(1, Math.max(0, x));
const toLinear = (c) => (c <= 0.04045 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4);
const toGamma = (c) => (c <= 0.0031308 ? 12.92 * c : 1.055 * c ** (1 / 2.4) - 0.055);

function oklabToLinear([L, a, b]) {
  const l = (L + 0.3963377774 * a + 0.2158037573 * b) ** 3;
  const m = (L - 0.1055613458 * a - 0.0638541728 * b) ** 3;
  const s = (L - 0.0894841775 * a - 1.291485548 * b) ** 3;
  return [
    4.0767416621 * l - 3.3077115913 * m + 0.2309699292 * s,
    -1.2684380046 * l + 2.6097574011 * m - 0.3413193965 * s,
    -0.0041960863 * l - 0.7034186147 * m + 1.707614701 * s,
  ];
}

function linearToOklab([r, g, b]) {
  const l = Math.cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b);
  const m = Math.cbrt(0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b);
  const s = Math.cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b);
  return [
    0.2104542553 * l + 0.793617785 * m - 0.0040720468 * s,
    1.9779984951 * l - 2.428592205 * m + 0.4505937099 * s,
    0.0259040371 * l + 0.7827717662 * m - 0.808675766 * s,
  ];
}

// Out-of-gamut colours keep their lightness and hue; chroma is lowered by
// binary search until the colour fits sRGB.
export function oklchToSrgb([L, C, H]) {
  const h = (H * Math.PI) / 180;
  const at = (c) => oklabToLinear([L, c * Math.cos(h), c * Math.sin(h)]).map(toGamma);
  const fits = (rgb) => rgb.every((v) => v >= -1e-6 && v <= 1 + 1e-6);
  let rgb = at(C);
  if (!fits(rgb)) {
    let lo = 0;
    let hi = C;
    for (let i = 0; i < 24; i++) {
      const mid = (lo + hi) / 2;
      if (fits(at(mid))) lo = mid;
      else hi = mid;
    }
    rgb = at(lo);
  }
  return rgb.map(clamp01);
}

export function srgbToOklch(rgb) {
  const [L, a, b] = linearToOklab(rgb.map(toLinear));
  const H = (Math.atan2(b, a) * 180) / Math.PI;
  return [L, Math.hypot(a, b), H < 0 ? H + 360 : H];
}

const hexToRgb = (hex) => [1, 3, 5].map((i) => parseInt(hex.slice(i, i + 2), 16) / 255);

export const toHex = (rgb) =>
  '#' + rgb.map((v) => Math.round(clamp01(v) * 255).toString(16).padStart(2, '0')).join('');

export function parseColor(value) {
  if (value === null || typeof value !== 'object') {
    throw new TokenError(`a colour must be a DTCG colour object, got ${JSON.stringify(value)}`);
  }
  const { colorSpace, components, hex, alpha } = value;
  if (alpha !== undefined && alpha !== 1) throw new TokenError('alpha is not supported yet');
  if (colorSpace === 'srgb') {
    if (hex) {
      const rgb = hexToRgb(hex.toLowerCase());
      if (components && components.some((c, i) => Math.abs(c * 255 - rgb[i] * 255) > 1)) {
        throw new TokenError(`hex ${hex.toLowerCase()} does not match components [${components.join(', ')}]`);
      }
      return rgb;
    }
    return components.map(clamp01);
  }
  if (colorSpace === 'oklch') return oklchToSrgb(components);
  throw new TokenError(`colour space ${colorSpace} is not supported`);
}

const luminance = (rgb) => {
  const [r, g, b] = rgb.map(toLinear);
  return 0.2126 * r + 0.7152 * g + 0.0722 * b;
};

export function contrast(a, b) {
  const [hi, lo] = [luminance(a), luminance(b)].sort((x, y) => y - x);
  return (hi + 0.05) / (lo + 0.05);
}
```

```js
// The build gates. Each returns a list of problems; any problem stops the
// build before a file is written.
import { parseColor, contrast, srgbToOklch } from './color.mjs';

export const EXT = 'in.akashshivanand.saral';

export function checkRoles(roles, modes) {
  const errors = [];
  for (const [mode, tokens] of Object.entries(modes)) {
    for (const role of roles) if (!tokens.has(role)) errors.push(`${mode}: missing role ${role}`);
  }
  return errors;
}

// Missing roles are reported by checkRoles, so a pair with a missing side is
// skipped here rather than reported twice.
export function checkPairs(pairs, modes) {
  const errors = [];
  for (const [mode, tokens] of Object.entries(modes)) {
    for (const { text, on, min } of pairs) {
      const a = tokens.get(text);
      const b = tokens.get(on);
      if (!a || !b) continue;
      const ratio = contrast(parseColor(a.value), parseColor(b.value));
      if (ratio < min) errors.push(`${mode}: ${text} on ${on} is ${ratio.toFixed(2)}:1, needs ${min}:1`);
    }
  }
  return errors;
}

// Counts distinct hues among chromatic colours (OKLCH chroma 0.04 or more)
// outside feedback.*, which carries status, not brand. Hues within 30
// degrees count as one.
export function checkPolicy(policy, modes) {
  const errors = [];
  if (policy.accentHues === undefined) return errors;
  for (const [mode, tokens] of Object.entries(modes)) {
    const hues = [];
    for (const [path, t] of tokens) {
      if (t.type !== 'color' || path.startsWith('feedback.')) continue;
      const [, C, H] = srgbToOklch(parseColor(t.value));
      if (C < 0.04) continue;
      const near = (h) => Math.min(Math.abs(h - H), 360 - Math.abs(h - H)) <= 30;
      if (!hues.some(near)) hues.push(H);
    }
    if (hues.length > policy.accentHues) {
      const list = hues.map((h) => `${Math.round(h)}°`).join(', ');
      errors.push(`${mode}: ${hues.length} accent hues (${list}), the theme policy allows ${policy.accentHues}`);
    }
  }
  return errors;
}

export function checkFluid(modes) {
  const errors = [];
  const seen = new Set();
  for (const tokens of Object.values(modes)) {
    for (const [path, t] of tokens) {
      const fluid = t.extensions?.[EXT]?.fluid;
      if (!fluid || seen.has(path) || /\brem\b/.test(fluid.preferred)) continue;
      seen.add(path);

    }
  }
  return errors;
```

```js
// Turns resolved tokens into the files Saral ships: theme CSS, a JS module
// per theme, and one Tailwind v4 theme map. primitive.* tokens are private to
// their theme and never written.
import { parseColor, toHex } from './color.mjs';
import { EXT } from './checks.mjs';
import { TokenError } from './errors.mjs';

const dash = (p) => p.replaceAll('.', '-');
const isPublic = (p) => !p.startsWith('primitive.');
const GENERIC = new Set(['serif', 'sans-serif', 'monospace', 'system-ui', 'ui-sans-serif', 'ui-serif', 'ui-monospace']);
const dim = (d) => (d.value === 0 ? '0' : `${d.value}${d.unit}`);

export const cssName = (path) => `--saral-${dash(path)}`;

export function cssValue(t) {
  const ext = t.extensions?.[EXT] ?? {};
  const v = t.value;
  switch (t.type) {
    case 'color':
      return toHex(parseColor(v));
    case 'dimension':
      return ext.fluid ? `clamp(${dim(ext.fluid.min)}, ${ext.fluid.preferred}, ${dim(ext.fluid.max)})` : dim(v);
    case 'duration':
      return dim(v);
    case 'cubicBezier':
      return `cubic-bezier(${v.join(', ')})`;
    case 'fontFamily':
      return [v].flat().map((f) => (GENERIC.has(f) ? f : `"${f}"`)).join(', ');
    case 'fontWeight':
      return String(v);
    case 'number':
      return `${v}${ext.cssUnit ?? ''}`;
    default:
      throw new TokenError(`type ${t.type} is not supported`);
  }
}

const LAYERS = '@layer saral.reset, saral.tokens, saral.components, saral.utilities;';
const decls = (entries, indent) => entries.map(([p, t]) => `${indent}${cssName(p)}: ${cssValue(t)};`).join('\n');

export function toCss(name, modes) {
  const light = [...modes.light].filter(([p]) => isPublic(p));
  const changed = [];
  for (const [p, t] of modes.dark ?? []) {
    if (!isPublic(p)) continue;
    const l = modes.light.get(p);
    if (!l || cssValue(l) !== cssValue(t)) changed.push([p, t]);
  }
  const reduced = light
    .filter(([, t]) => t.extensions?.[EXT]?.reduced)
    .map(([p, t]) => [p, { type: t.type, value: t.extensions[EXT].reduced, extensions: {} }]);
  const own = `[data-saral-theme="${name}"]`;
  const root = ':root:not([data-saral-theme])';
  const out = [
    `/* Generated by Saral from tokens/themes/${name}. Do not edit. */`,
    LAYERS,
    '@layer saral.tokens {',
    `  :where(${root}, ${own}) {`,
    '    color-scheme: light;',
    decls(light, '    '),
    '  }',
  ];
  if (changed.length) {
    out.push(
      '  @media (prefers-color-scheme: dark) {',
      `    :where(${root}:not([data-saral-mode="light"]), ${own}:not([data-saral-mode="light"])) {`,
      '      color-scheme: dark;',
      decls(changed, '      '),
      '    }',
      '  }',
      `  :where(:root[data-saral-mode="dark"]:not([data-saral-theme]), ${own}[data-saral-mode="dark"]) {`,
      '    color-scheme: dark;',
      decls(changed, '    '),
      '  }',
    );
  }
  if (reduced.length) {
    out.push('  @media (prefers-reduced-motion: reduce) {', `    :where(${root}, ${own}) {`, decls(reduced, '      '), '    }', '  }');
  }
  out.push('}', '');
  return out.join('\n');
}

export function toJs(name, modes) {
  const obj = {};
  for (const [mode, tokens] of Object.entries(modes)) {
    obj[mode] = {};
    for (const [p, t] of tokens) if (isPublic(p)) obj[mode][p] = cssValue(t);
  }
  return `// Generated by Saral from tokens/themes/${name}. Do not edit.\nexport default ${JSON.stringify(obj, null, 2)};\n`;
}

function twName(p, t) {
  if (t.type === 'color') return `--color-${dash(p)}`;
  if (p.startsWith('radius.')) return `--radius-${dash(p.slice(7))}`;
  if (p.startsWith('font.family.')) return `--font-${dash(p.slice(12))}`;
  if (p.startsWith('font.size.')) return `--text-${dash(p.slice(10))}`;
  if (p.startsWith('space.')) return `--spacing-${dash(p.slice(6))}`;
  if (t.type === 'cubicBezier') return `--ease-${p.split('.').at(-1)}`;
  return null;
}

export function toTailwind(tokens) {
  const lines = [];
  for (const [p, t] of tokens) {
    const tw = isPublic(p) && twName(p, t);
    if (tw) lines.push(`  ${tw}: var(${cssName(p)});`);
  }
  return ['/* Generated by Saral. Do not edit. Load after a Saral theme. */', '@theme inline {', ...lines, '}', ''].join('\n');
}
```

`packages/tokens/src/build.mjs`:

```js
#!/usr/bin/env node
// Builds every theme in tokens/themes into dist/. Runs every check first and
// writes nothing if any check fails. With --check, writes nothing and exits 1
// when dist/ does not match the source.
import { readFileSync, readdirSync, writeFileSync, mkdirSync, existsSync } from 'node:fs';
import { join, dirname } from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';
import { loadResolver, flatten, resolveAliases } from './resolve.mjs';
import { checkRoles, checkPairs, checkPolicy, checkFluid } from './checks.mjs';
import { toCss, toJs, toTailwind } from './outputs.mjs';
import { TokenError } from './errors.mjs';

export const ROOT = join(dirname(fileURLToPath(import.meta.url)), '..', '..', '..');

const readJson = (file) => JSON.parse(readFileSync(file, 'utf8'));

export function buildTheme(dir) {
  const resolver = join(dir, 'theme.resolver.json');
  const contexts = Object.keys(readJson(resolver).modifiers?.theme?.contexts ?? { light: [] });
  const modes = {};
  for (const ctx of contexts) modes[ctx] = resolveAliases(flatten(loadResolver(resolver, { theme: ctx })));
  return modes;
}

export function buildAll(root = ROOT) {
  const tokens = join(root, 'tokens');
  const { roles } = readJson(join(tokens, 'roles.json'));
  const { pairs } = readJson(join(tokens, 'pairs.json'));
  const files = new Map();
  const errors = [];
  let first;
  for (const name of readdirSync(join(tokens, 'themes')).sort()) {
    const dir = join(tokens, 'themes', name);
    try {
      const modes = buildTheme(dir);
      const policy = existsSync(join(dir, 'policy.json')) ? readJson(join(dir, 'policy.json')) : {};
      const found = [...checkRoles(roles, modes), ...checkPairs(pairs, modes), ...checkPolicy(policy, modes), ...checkFluid(modes)];
      if (found.length) {
        errors.push(...found.map((e) => `${name}: ${e}`));
        continue;
      }
      files.set(`dist/css/${name}.css`, toCss(name, modes));
      files.set(`dist/js/${name}.mjs`, toJs(name, modes));
      first ??= modes.light;
    } catch (e) {
      if (!(e instanceof TokenError)) throw e;
      errors.push(`${name}: ${e.message}`);
    }
  }
  if (first) files.set('dist/tailwind/saral.css', toTailwind(first));
  return { files, errors };
}

function main(argv) {
  const check = argv.includes('--check');
  const { files, errors } = buildAll();
  if (errors.length) {
    for (const e of errors) console.error(`tokens: ${e}`);
    console.error(`tokens: ${errors.length} problem(s). Nothing written.`);
    return 1;
  }
  let stale = 0;
  for (const [rel, text] of files) {
    const file = join(ROOT, rel);
    if (existsSync(file) && readFileSync(file, 'utf8') === text) continue;
    if (check) {
      console.error(`tokens: ${rel} is out of date. Run npm run build.`);
      stale += 1;
      continue;
    }
    mkdirSync(dirname(file), { recursive: true });
    writeFileSync(file, text);
    console.log(`tokens: wrote ${rel}`);
  }
  if (stale) return 1;
  console.log(check ? 'tokens: dist is up to date' : 'tokens: built');
  return 0;
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  process.exit(main(process.argv.slice(2)));
}
```

```markdown
# 0001: Token pipeline

Status: adopted, 2026-10-12

## Decision

- Tokens are written in DTCG 2025.10. Each theme has a resolver file with one set (shared tokens plus the theme's core) and one `theme` modifier with light and dark contexts. Saral reads the subset it uses: `{ "$ref" }` sources and whole-value aliases.
- Saral data with no DTCG type (font width, fluid sizes, reduced motion) lives under `$extensions` key `in.akashshivanand.saral`.
- A small own compiler, not Style Dictionary or Terrazzo, because neither covered the resolver and every planned output in October 2026.
- Generated files in `dist/` are committed, because the website installs Saral from a git tag with no build step. CI fails if `dist/` is stale.
- Theme CSS applies to `:root` without a theme attribute, or to an element with `data-saral-theme`, so several themes can sit on one page. `data-saral-mode` forces light or dark.

## Why

The research in `docs/research/` found that systems whose styling engine sat under their public interface forced migrations. Plain CSS custom properties, generated from one source, are the smallest public contract.
```
