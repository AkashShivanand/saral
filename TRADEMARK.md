# The Saral name

The code is MIT licensed. The name is not part of that licence.

## You can

- Use Saral in any project, free or paid, and say that it is built with Saral.
- Fork it, change it and ship your fork.
- Write about Saral, teach it and link to it.

## You cannot

- Call a fork or a changed copy "Saral", or a name that could be mistaken for it.
- Suggest that your product, template or service is made, endorsed or supported by the Saral project when it is not.

If you ship a fork, give it its own name and say it is based on Saral.

Questions about the name go in a GitHub issue.
